## 실제 근본 원인: RDS 다운 중 헥토 처리 성공 → DB 기록 소실

두 날짜 모두 **RDS가 다운된 시간대에 헥토 출금이 성공**하여 우리 DB에 기록을 남기지 못한 것이 공통 원인이다.

> **Hecto API 성공 응답 수신 후 DB INSERT 시 RDS 불가 상태이면 → 재처리 없이 기록 전체 소실**

초기에 "패턴 A(콜백 누락), 패턴 B(트랜잭션 롤백)"으로 분류했으나, RDS 이벤트 로그 확인 결과 두 케이스 모두 **RDS 다운**이 직접 원인임이 확인되었다. RDS 다운 원인만 다를 뿐(엔진 업그레이드 vs OOM)이다.
