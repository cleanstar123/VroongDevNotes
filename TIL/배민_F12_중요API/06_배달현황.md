# 배달 관리 > 배달 현황 API (실시간)

- **URL** : `https://api-deliverycenter.baemin.com/management/delivery-status`
- **Method** : GET
- **페이지** : 배달 관리 > 배달 현황 (실시간 라이더 배달 상태)

---

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `page` | `0` | 페이지 번호 |
| `size` | `20` | 페이지당 항목 수 |
| `orderName` | `name` | 정렬 기준 컬럼 |
| `orderBy` | `asc` | 정렬 방향 (asc/desc) |
| `name` | `` | 이름 검색 (선택) |
| `userId` | `` | 아이디 검색 (선택) |
| `phoneNumber` | `` | 전화번호 검색 (선택) |
| `riderStatus` | `` | 라이더 상태 필터 (선택) |

**예시 URL**
```
/management/delivery-status?page=0&size=20&orderName=name&orderBy=asc&name=&userId=&phoneNumber=&riderStatus=
```

## 배치 연계

- 배치 잡: `riderDeliveryHistoriesNowJob`
- 스케줄: 시간대별 3~10분 간격 (24시간)
- 일별 배달내역/라이더별 배달내역과 달리 **실시간** 현황 조회용
