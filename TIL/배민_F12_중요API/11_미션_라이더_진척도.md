# 배민 미션 라이더 진척도 API

- **URL** : `https://api-deliverycenter.baemin.com/v1/center/missions/achieve/{missionId}`
- **Method** : GET
- **용도** : 특정 미션의 전체 라이더 달성 현황 조회 (v2 상세 API와 유사하나 구버전)

> 미션 현황 상세(`/v2/center/missions/{id}/riders`)와 차이점:
> - v1은 `promotionAchieveStatus` 문자열로 상태 반환
> - v2는 `rewards[]` 배열로 상세 구조 반환

---

## Path Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `missionId` | `875AXOE7R4SV` | 미션 ID |

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `page` | `0` | 페이지 번호 |
| `size` | `10` | 페이지당 항목 수 |

**예시 URL**
```
/v1/center/missions/achieve/875AXOE7R4SV?page=0&size=10
```

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2603305842` |

### data[] 필드

| 필드 | 설명 |
|------|------|
| `brmsRiderId` | 라이더 고유 ID |
| `name` | 라이더 이름 |
| `phoneNumber` | 전화번호 (- 없음) |
| `progress` | 현재 달성 건수 |
| `goal` | 목표 건수 |
| `promotionAchieveStatus` | 달성 상태 |
| `underContract` | 계약 여부 |

### promotionAchieveStatus 값

| 값 | 설명 |
|----|------|
| `WAITING` | 참여대기중 |
| `IN_PROGRESS` | 진행중 |
| `ACHIEVED` | 달성 |
| `FAILED` | 미달성 |
