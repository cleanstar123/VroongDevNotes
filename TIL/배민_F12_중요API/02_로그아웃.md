# 배민 로그아웃 API

- **URL** : `https://api-deliverycenter.baemin.com/logout`
- **Method** : POST (앞서 OPTIONS preflight 자동 발생)
- **페이지** : `https://deliverycenter.baemin.com` 우측 상단 로그아웃 버튼 클릭 시

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2503217137` (현재 선택된 센터 ID) |
| `origin` | `https://deliverycenter.baemin.com` |

### 요청 쿠키 (필수)

| 쿠키 | 설명 |
|------|------|
| `CENTER_SESSION` | 현재 세션 토큰 |
| `__cf_bm` | Cloudflare Bot Management |

---

## Response

- Body 없음 (빈 응답)
- Status: 200 OK

### Response Set-Cookie (세션 무효화)

| 쿠키 | Max-Age | 설명 |
|------|---------|------|
| `_ceo_v2_gk_sid` | 0 (즉시 만료) | 세션 삭제 |
| `CENTER_SESSION` | 0 (즉시 만료) | 세션 삭제 |
