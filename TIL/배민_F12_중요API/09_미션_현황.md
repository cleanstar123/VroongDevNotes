# 배민 미션 현황 페이지 API

- **URL** : `https://api-deliverycenter.baemin.com/v2/center/missions/current`
- **Method** : GET
- **페이지** : 미션 현황

---

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `page` | `0` | 페이지 번호 |
| `size` | `10` | 페이지당 항목 수 |

**예시 URL**
```
/v2/center/missions/current?page=0&size=10
```

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2503141419` |

### promotionType 코드값

| code | description |
|------|-------------|
| `DELIVERY_COUNT_PROMOTION` | 배달건수 미션 |

### promotionStatus 코드값

| code | description |
|------|-------------|
| `RESERVED` | 예약중 |
| `IN_PROGRESS` | 진행중 |
| `COMPLETED` | 완료 |

### channel 코드값

| code | description |
|------|-------------|
| `RPM_ADMIN` | 본사 |
| `CENTER` | 협력사 |

### 주요 필드

| 필드 | 설명 |
|------|------|
| `id` | 미션 ID (상세 조회 시 경로 파라미터로 사용) |
| `deliveryCount` | 목표 배달 건수 |
| `rewardAmount` | 보상 금액 (원) |
| `rewardType` | 보상 유형 (CASH 등) |
| `promotionStartDateTime` | 미션 시작일시 |
| `promotionEndDateTime` | 미션 종료일시 |

## 배치 연계

- 배치 잡: `baeminCenterMissionIfJob`
- 미션 현황을 주기적으로 크롤링하여 `baemin_center_mission_if` 테이블에 저장
