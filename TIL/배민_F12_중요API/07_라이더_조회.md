# 라이더 관리 > 라이더 조회 API

- **URL** : `https://api-deliverycenter.baemin.com/rider`
- **Method** : GET
- **페이지** : 라이더 관리 > 라이더 조회

---

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `name` | `` | 이름 검색 |
| `userId` | `` | 배민 아이디 검색 |
| `phoneNumber` | `` | 전화번호 검색 (- 제외 숫자) |
| `accountStatus` | `` | 계약 상태 필터 |
| `orderName` | `` | 정렬 기준 컬럼 |
| `orderBy` | `` | 정렬 방향 |

**accountStatus 값**
- (빈값): 전체
- `UNDER_CONTRACT`: 계약중
- `CONTRACT_EXPIRED`: 계약종료

**예시 URL**
```
/rider?name=&userId=&phoneNumber=&accountStatus=&orderName=&orderBy=
```

### accountStatus 코드값

| code | desc |
|------|------|
| `UNDER_CONTRACT` | 계약중 |
| `CONTRACT_EXPIRED` | 계약종료 |

### insuranceStatus 코드값

| code | desc |
|------|------|
| `VALID` | 유효 |
| `INVALID` | 무효 |
| `DONT_CARE` | 무관 |

### insuranceType 코드값

| code | desc |
|------|------|
| `BIKE_ON_DEMAND_HYUNDAI` | 현대해상 오토바이 시간제보험 |
| `BIKE_ON_DEMAND_DB` | DB 오토바이 시간제보험 |
| `PERSONAL` | 개인유상운송보험 |
| `NOT_SELECTED` | 보험 미적용 |

### deliveryMethod 코드값

| code | desc |
|------|------|
| `BIKE` | 오토바이 |

## 배치 연계

- 배치 잡: `riderInfoJob`
- 스케줄: `0 0 0-3,7-23 * * ?` (매시 정각, 4~6시 제외)
- **보험 상태가 실시간으로 변할 수 있어** 하루 여러 번 크롤링 필요 (정산에 영향)
