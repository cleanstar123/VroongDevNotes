# 배민 미션 현황 상세 페이지 API

- **URL** : `https://api-deliverycenter.baemin.com/v2/center/missions/{missionId}/riders`
- **Method** : GET
- **페이지** : 미션 현황 > 상세 (특정 미션의 라이더별 진척도)

---

## Path Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `missionId` | `87ABFX9AL1O5` | 미션 ID (미션 현황 API에서 획득) |

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `page` | `0` | 페이지 번호 |
| `size` | `10` | 페이지당 항목 수 |

**예시 URL**
```
/v2/center/missions/87ABFX9AL1O5/riders?page=0&size=10
```

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2503141419` |

---

## Response

```json
{
    "page": 0,
    "size": 10,
    "total": 4,
    "totalPage": 1,
    "data": [
        {
            "riderId": "25012719367354771880",
            "riderName": "장동근",
            "riderPhoneNumber": "01024850100",
            "underContract": true,
            "rewards": [
                {
                    "rewardCondition": {
                        "code": "DELIVERY_COUNT",
                        "description": "배달건수"
                    },
                    "step": 0,
                    "goal": 10,
                    "progress": 0,
                    "status": {
                        "code": "WAITING",
                        "description": "참여대기중"
                    }
                }
            ]
        }
    ]
}
```

### data[] 필드

| 필드 | 설명 |
|------|------|
| `riderId` | 라이더 고유 ID (brmsRiderId) |
| `riderName` | 라이더 이름 |
| `riderPhoneNumber` | 전화번호 (- 없음) |
| `underContract` | 현재 계약 여부 |
| `rewards[].goal` | 목표 배달 건수 |
| `rewards[].progress` | 현재 진척 건수 |
| `rewards[].status.code` | 달성 상태 |

### rewards[].status 코드값

| code | description |
|------|-------------|
| `WAITING` | 참여대기중 |
| `IN_PROGRESS` | 진행중 |
| `ACHIEVED` | 달성 |
| `FAILED` | 미달성 |

---

## 배치 연계

- 배치 잡: `baeminRiderMissionProgressIfJob`
- 미션별 라이더 진척도를 크롤링하여 `baemin_rider_mission_progress_if` 테이블에 저장
