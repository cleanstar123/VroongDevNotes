# 협력사 선택 페이지 API

- **URL** : `https://api-deliverycenter.baemin.com/v2/center`
- **Method** : GET
- **페이지** : 로그인 후 협력사 선택 화면

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2504185235` (현재 선택된 센터 ID) |
| `origin` | `https://deliverycenter.baemin.com` |

---

## Response

```json
{
    "isHeadquarter": false,
    "headquarterId": null,
    "headquarterName": null,
    "data": [
        {
            "id": "DP2504258339",
            "name": "강원동해A부릉라이더스1",
            "headquarterName": "주식회사 부릉라이더스",
            "role": "MANAGER"
        },
        ...
    ]
}
```

### 응답 필드

| 필드 | 설명 |
|------|------|
| `isHeadquarter` | 본사 계정 여부 |
| `headquarterId` | 본사 ID (null이면 일반 협력사) |
| `data[].id` | 센터 ID (이후 모든 API에서 `center-id` 헤더로 사용) |
| `data[].name` | 센터명 |
| `data[].headquarterName` | 소속 본사명 |
| `data[].role` | 권한 (MANAGER 등) |

---

## 활용 방법

이 API에서 받은 `data[].id` 값이 이후 모든 API 호출 시 `center-id` 헤더 값으로 사용됨.

```
GET /management/delivery-status
Header: center-id: DP2504258339
```

## 참고: 협력사 변경 시 발생하는 3rd party 트래킹

협력사 선택(변경) 시 아래 두 호출이 추가로 발생하나, 배민 비즈니스 로직과 무관:
