## 필수 쿠키

모든 API 호출 시 아래 쿠키가 요청에 포함되어야 함.

| 쿠키명 | 도메인 | 설명 | 만료 |
|--------|--------|------|------|
| `CENTER_SESSION` | `.baemin.com` | 주요 세션 인증 (HttpOnly, Secure, SameSite=Lax) | 브라우저 세션 |
| `__cf_bm` | `.baemin.com` | Cloudflare Bot Management | 30분 |
| `_ceo_v2_gk_sid` | `.baemin.com` | 배민 세션 ID | 1년 |
| `dsid` | `.baemin.com` | 기기 세션 ID | 장기 |

> `CENTER_SESSION`이 가장 핵심. 만료되면 401 응답.

## 로그인 흐름 요약

```
1. GET /v1/login/init → tag(RSA공개키) 획득
2. RSA 암호화 (tag로 pw, value1, value2 암호화)
3. POST /v1/login → CENTER_SESSION 쿠키 발급
4. GET /v2/center → 협력사 목록 조회 → center-id 선택
5. 이후 API 호출 시 center-id 헤더 + 쿠키 포함
```
