# 배민 로그인 API

## 흐름 요약
1. `GET /v1/login/init` → RSA 암호화 키(`tag`) 획득
2. `POST /v1/login` → 암호화된 pw/value1/value2 전송

---

## 1. 로그인 초기화 (암호화 키 획득)

- **URL** : `https://biz-member.baemin.com/v1/login/init?__ts={timestamp}`
- **Method** : GET

### Response

```json
{
    "status": "SUCCESS",
    "message": "성공",
    "serverDatetime": "2026-09-01 08:46:32",
    "data": {
        "tag": "9357baa6....(RSA 공개키)",
        "value": "10001",
        "needRecaptcha": false
    }
}
```

| 필드 | 설명 |
|------|------|
| `tag` | RSA 공개키 (이후 pw/value1/value2 암호화에 사용) |
| `value` | RSA 지수 (항상 10001) |
| `needRecaptcha` | recaptcha 필요 여부 |

---

## 2. 로그인

- **URL** : `https://biz-member.baemin.com/v1/login?__ts={timestamp}`
- **Method** : POST
- **Content-Type** : application/json

### 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `sec-ch-ua` | `"Not=A?Brand";v="99", "Google Chrome";v="151", "Chromium";v="151"` |
| `user-agent` | `Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...Chrome/151.0.0.0...` |
| `Referer` | `https://biz-member.baemin.com/login?returnUrl=https%3A%2F%2Fdeliverycenter.baemin.com` |

### Request Payload

```json
{
    "id": "계정아이디",
    "pw": "RSA암호화된_비밀번호",
    "token": "",
    "autoLogin": false,
    "value1": "RSA암호화된_value1",
    "value2": "RSA암호화된_value2"
}
```

### Response

```json
{
    "status": "SUCCESS",
    "message": "성공",
    "serverDatetime": "2026-09-01 08:46:32",
    "data": {
        "sessionId": "9d7b64a8-4476-451f-a4ac-cd591eb3e25c",
        "needPasswordChange": false,
        "needCheckIdentity": false
    }
}
```

### 주요 쿠키 (Response Set-Cookie)

| 쿠키 | 설명 |
|------|------|
| `_ceo_v2_gk_sid` | 로그인 세션 ID (365일) |

### 로그인 성공 후 필요한 쿠키

| 쿠키 | 도메인 | 설명 |
|------|--------|------|
| `CENTER_SESSION` | `.baemin.com` | 세션 인증 (HttpOnly, Secure, Lax) |
| `__cf_bm` | `.baemin.com` | Cloudflare Bot Management (30분) |
| `_ceo_v2_gk_sid` | `.baemin.com` | 배민 세션 (1년) |

## HTML 입력 셀렉터

```html
<!-- 아이디 -->
<input type="text" name="id" data-testid="id" placeholder="아이디">

<!-- 비밀번호 -->
<input type="password" name="password" data-testid="password" placeholder="비밀번호">

<!-- 로그인 버튼 -->
<button type="submit">로그인</button>
```

> 셀렉터 우선순위: `[data-testid="id"]` > `input[name="id"]` > `input[type="text"]`
