# 배달 관리 > 라이더별 배달내역 API

- **URL** : `https://api-deliverycenter.baemin.com/management/rider-delivery-status`
- **Method** : GET
- **페이지** : 배달 관리 > 라이더별 배달내역

---

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `page` | `0` | 페이지 번호 (0부터 시작) |
| `size` | `20` | 페이지당 항목 수 |
| `fromDate` | `2025-09-27` | 조회 시작일 (yyyy-MM-dd) |
| `toDate` | `2025-09-29` | 조회 종료일 (yyyy-MM-dd) |

**예시 URL**
```
/management/rider-delivery-status?page=0&size=20&fromDate=2025-09-27&toDate=2025-09-29
```

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2504254539` |

### data[] 항목 필드

| 필드 | 설명 |
|------|------|
| `phoneNumber` | 라이더 전화번호 |
| `userId` | 라이더 배민 아이디 |
| `name` | 라이더 이름 |
| `deliveryAcceptanceCount.complete` | 완료 건수 |
| `deliveryAcceptanceCount.reject` | 거절 건수 |
| `deliveryAcceptanceCount.cancel` | 취소 건수 |
| `deliveryAcceptanceCount.riderFault` | 라이더 귀책 건수 |
| `deliveryPeakTimeCount.morning` | 오전 배달 수 |
| `deliveryPeakTimeCount.afternoon` | 점심 배달 수 |
| `deliveryPeakTimeCount.evening` | 저녁 배달 수 |
| `deliveryPeakTimeCount.midnight` | 야간 배달 수 |

## 배치 연계

- 배치 잡: `riderDeliveryHistoriesJob`
- 스케줄: `0 4,17 10 * * ?` (매일 10:04, 10:17)
- relay 서버 내부 엔드포인트: `GET /api/v1/delivery/rider-delivery-history?fromDate=&toDate=`
