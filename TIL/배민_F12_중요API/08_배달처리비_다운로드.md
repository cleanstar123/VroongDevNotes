# 협력사 관리 > 배달처리비 다운로드 API

- **URL** : `https://api-deliverycenter.baemin.com/v2/management/delivery-fee`
- **Method** : GET
- **페이지** : 협력사 관리 > 배달처리비 다운로드
- **응답 형식** : xlsx 파일 (엑셀)

---

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `reason` | `테스트` | 다운로드 사유 (필수, 최대 40자) |
| `fromDate` | `2026-01-06` | 조회 시작일 (yyyy-MM-dd) |
| `toDate` | `2026-01-08` | 조회 종료일 (yyyy-MM-dd) |

**예시 URL**
```
/v2/management/delivery-fee?reason=테스트&fromDate=2026-01-06&toDate=2026-01-08
```

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2504258339` |

---

## Response Headers

| 헤더 | 값 | 설명 |
|------|-----|------|
| `content-type` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` | xlsx 파일 |
| `content-disposition` | `attachment; filename=배달처리비_{센터명}_{fromDate}_{toDate}.xlsx` | 다운로드 파일명 |
| `content-length` | `51200` | 파일 크기 (bytes) |

**파일명 예시**
```
배달처리비_강원동해A부릉라이더스1_20260106_20260108.xlsx
```

---

## UI 흐름

1. 기간 선택 (버튼: 3일/7일/1개월/3개월 또는 직접 DatePicker)
2. 엑셀 다운로드 버튼 클릭
3. 사유 입력 모달 팝업 → 사유 입력 (최대 40자)
4. 모달 내 엑셀 다운로드 버튼 클릭 → API 호출

---

## 참고

- `reason` 파라미터가 비어있으면 다운로드 불가 (사유 필수 입력)
- 응답이 JSON이 아닌 바이너리(xlsx)이므로 파일로 저장 처리 필요
