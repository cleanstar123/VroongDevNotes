# 배달 관리 > 일별 배달내역 API

- **URL** : `https://api-deliverycenter.baemin.com/management/daily-delivery-status`
- **Method** : GET
- **페이지** : 배달 관리 > 일별 배달내역

---

## Query Parameters

| 파라미터 | 예시 | 설명 |
|----------|------|------|
| `page` | `0` | 페이지 번호 (0부터 시작) |
| `size` | `20` | 페이지당 항목 수 |
| `fromDate` | `2025-09-26` | 조회 시작일 (yyyy-MM-dd) |
| `toDate` | `2025-09-28` | 조회 종료일 (yyyy-MM-dd) |

**예시 URL**
```
/management/daily-delivery-status?page=0&size=20&fromDate=2025-09-26&toDate=2025-09-28
```

---

## 주요 Request Headers

| 헤더 | 값 |
|------|-----|
| `center-id` | `DP2504257956` |

---

## Response

```json
{
    "deliveryStatusTotalResponse": {
        "totalCount": 0,
        "totalCompleted": 0,
        "totalRejected": 0,
        "totalCanceled": 0,
        "totalRiderFault": 0,
        "totalMorningCompleted": 0,
        "totalLunchCompleted": 0,
        "totalDinnerCompleted": 0,
        "totalNightCompleted": 0
    },
    "page": 0,
    "size": 20,
    "total": 0,
    "totalPage": 0,
    "data": []
}
```

### deliveryStatusTotalResponse 필드

| 필드 | 설명 |
|------|------|
| `totalCount` | 전체 라이더 수 |
| `totalCompleted` | 총 완료 건수 |
| `totalRejected` | 총 거절 건수 |
| `totalCanceled` | 총 취소 건수 |
| `totalRiderFault` | 라이더 귀책 건수 |
| `totalMorningCompleted` | 오전 완료 건수 |
| `totalLunchCompleted` | 점심 완료 건수 |
| `totalDinnerCompleted` | 저녁 완료 건수 |
| `totalNightCompleted` | 야간 완료 건수 |

---

## 배치 연계

- 배치 잡: `deliveryDailyHistoriesJob`
- 스케줄: `0 2,16 10 * * ?` (매일 10:02, 10:16)
- relay 서버 내부 엔드포인트: `GET /api/v1/delivery/daily-delivery-status?fromDate=&toDate=`
