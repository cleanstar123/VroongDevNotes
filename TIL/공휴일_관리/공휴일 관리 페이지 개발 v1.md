# 공휴일 관리 페이지 개발 v1

작성일: 2026-07-28

---

## 개요

공휴일 날짜에 슬롯 목표 물량을 실제 요일(예: 수요일) 기준이 아닌, 지정한 요일(예: 일요일)의 목표치로 대체 적용하기 위한 기능.  
대시보드 주별 수행률 계산 시 공휴일이 반영되지 않는 문제를 해결한다.

---

## DB 테이블

```sql
CREATE TABLE `vr_holiday` (
  `SEQ_NO`        bigint       NOT NULL AUTO_INCREMENT,
  `HOLIDAY_DATE`  varchar(10)  NOT NULL COMMENT '날짜 YYYY-MM-DD',
  `HOLIDAY_NAME`  varchar(100) NOT NULL COMMENT '공휴일명',
  `TARGET_DOW`    int          NOT NULL DEFAULT 7 COMMENT '적용 요일 (1=월~7=일, getDayOfWeek 기준)',
  `IS_SUBSTITUTE` char(1)      NOT NULL DEFAULT 'N' COMMENT '대체공휴일 여부',
  `USE_YN`        char(1)      NOT NULL DEFAULT 'Y',
  `INS_DATE`      datetime     DEFAULT NULL,
  `INS_USER`      varchar(50)  DEFAULT NULL,
  `UPD_DATE`      datetime     DEFAULT NULL,
  `UPD_USER`      varchar(50)  DEFAULT NULL,
  PRIMARY KEY (`SEQ_NO`),
  UNIQUE KEY `uq_holiday_date` (`HOLIDAY_DATE`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='공휴일 관리';
```

### 핵심 컬럼

| 컬럼 | 설명 |
|------|------|
| `HOLIDAY_DATE` | 공휴일 날짜 (YYYY-MM-DD, UNIQUE) |
| `HOLIDAY_NAME` | 공휴일명 / 변동 사유 |
| `TARGET_DOW` | 이 날짜에 적용할 슬롯 목표 기준 요일 (1=월~7=일) |
| `IS_SUBSTITUTE` | 대체공휴일 여부 (Y/N) |
| `USE_YN` | 사용 여부 — N이면 달성률 계산에서 제외 |

> `TARGET_DOW`는 Java `DayOfWeek.getValue()` 기준(1=월~7=일)과 동일하게 맞춰 변환 없이 바로 사용한다.  
> 공휴일은 보통 토요일(6) 또는 일요일(7) 물량 기준으로 설정한다.

## 대시보드 달성률 반영 로직

### 핵심 아이디어

`DashboardQueryDslRepository.getWeeklyPerformance()`에서 날짜별 슬롯 목표 물량을 계산할 때,  
해당 날짜가 공휴일이면 **실제 요일 대신 `TARGET_DOW`에 해당하는 요일의 목표치**를 사용한다.

### 추가된 메서드

```java
// 1. 조회 기간 내 공휴일을 Map<yyyyMMdd, targetDow>로 로드
private Map<String, Integer> loadHolidayMap(String fromDate, String toDate)

// 2. 공휴일이면 targetDow, 아니면 getDayOfWeek(date) 반환
private int getEffectiveDow(String date, Map<String, Integer> holidayDowMap)
```

### 적용 범위

`getEffectiveDow()`는 아래 4개 지점에 적용된다.

| 메서드 | 설명 |
|--------|------|
| `buildDailyPerformances()` | 일별 성과 데이터 (집계 뷰) |
| `calculateSlotAchievementOptimized()` — 특정 협력사 | 협력사 지정 모드 슬롯 달성률 |
| `calculateSlotAchievementOptimized()` — 전체 협력사 | 전체 모드 슬롯 달성률 |
| `buildSupplierPerformancesOptimized()` | 협력사별 일별 슬롯 성과 |

### 정책 있는 협력사 vs 없는 협력사

두 경우 모두 `getEffectiveDow()`를 통해 동일한 방식으로 처리된다.

```
공휴일(예: 1월 1일 수요일, TARGET_DOW=7)

├── 정책 있는 협력사
│   → policySlotTargets의 val7 (일요일 목표) 사용
│
└── 정책 없는 협력사 (SLOTINFO 기본)
    → slotTargets["SLOT1~4"][7] (일요일 목표) 사용
```

### targetDow 값 기준

| 값 | 요일 |
|----|------|
| 1 | 월 |
| 2 | 화 |
| 3 | 수 |
| 4 | 목 |
| 5 | 금 |
| 6 | 토 |
| 7 | 일 |

Java `DayOfWeek.getValue()`와 동일하므로 변환 없이 바로 Map 키로 사용한다.

## 주의사항

- `vr_holiday.TARGET_DOW` 기본값은 **7** (일요일). DDL에서 `DEFAULT 7`로 설정할 것.
- 자동 동기화 시 등록되는 `TARGET_DOW`는 해당 공휴일의 **실제 요일**이므로, 등록 후 필요에 따라 수동으로 6(토) 또는 7(일)로 수정해야 한다.
- `HOLIDAY_DATE`에 UNIQUE 제약이 있어 동일 날짜 중복 등록 불가. 동기화 시 기존 데이터는 건너뛴다.
- `USE_YN = N`인 항목은 달성률 계산에 포함되지 않으며, 동기화 시 복구(Y로 변경)된다.
