## 3. 방법 A: 계정 정보 변경 절차 ★ 권장

> 앱 재심사 없이 메타데이터만 변경. 앱 연속성이 완전히 유지됨.

| 순서 | 단계 | 상세 내용 | 비고 |
|------|------|---------|------|
| 1 | Play Console 접속 | https://play.google.com/console 접속 후 `cleanstar1212@gmail.com` 으로 로그인 | |
| 2 | 계정 정보 메뉴 이동 | 좌측 메뉴 → **설정** → **개발자 계정** → **계정 세부정보** | |
| 3 | 개발자 이름 변경 | `Umac ITC` → VROONG 측 희망 이름으로 수정 | |
| 4 | 조직 세부정보 변경 | 조직명, 주소, 웹사이트를 VROONG 정보로 수정 | |
| 5 | 개발자 연락처 변경 | 개발자 이메일, 전화번호를 VROONG 대표 연락처로 수정 | |
| 6 | 변경사항 저장 | **저장** 클릭 — Google Play 반영까지 수일 소요될 수 있음 | |
| 7 | 계정 소유자 Google 계정 이전 | 설정 → **사용자 및 권한** → **초대** → VROONG 계정 추가 후 `계정 소유자` 권한 부여 → 기존 소유자 제거 | VROONG 계정이 먼저 초대 수락해야 함 |

## 4. 방법 B: 신규 계정으로 앱 이전 절차

> 이전 진행 중 앱 업데이트 불가. 완전한 계정 분리가 필요할 때만 선택.

| 순서 | 단계 | 상세 내용 | 비고 |
|------|------|---------|------|
| 1 | VROONG 신규 계정 생성 | VROONG 대표 Google 계정으로 Play Console 가입 → 개발자 등록비 결제 | |
| 2 | 신규 계정 ID 확인 | VROONG 계정의 개발자 계정 ID(숫자 18자리) 확인 후 메모 | 이전 시 필요 |
| 3 | 앱 이전 시작 (기존 계정) | Play Console → 앱 선택 → **설정** → **고급 설정** → **앱 이전** 클릭 | |
| 4 | 수신 계정 ID 입력 | VROONG 개발자 계정 ID 입력 후 이전 요청 전송 | |
| 5 | 이전 수락 (VROONG 계정) | VROONG 계정 Play Console 로그인 → 알림에서 이전 요청 수락 | **72시간 내 수락 필요** |
| 6 | 이전 완료 확인 | VROONG 계정에서 앱 정상 표시 확인, 스토어 정보 검토 | |
| 7 | 기존 계정 정리 | 이전 완료 후 Umac ITC 계정 정리 또는 폐쇄 | |

---

## 5. 중요 주의사항

> ⚠️ **앱 이전(방법 B) 진행 중에는 앱 업데이트/새 버전 제출 불가** — 이전 완료 후 재개 가능

> ⚠️ **앱 서명 키(App Signing Key)는 이전 시 함께 이전됨** — 별도 키 관리 불필요

> ⚠️ **구독, 인앱결제 내역, 리뷰/평점은 이전 후에도 유지됨**

> ⚠️ **계정 정보 변경(방법 A)은 앱 재심사 없음** — 단순 메타데이터 변경

> ⚠️ **계정 소유자 이전 시 VROONG 계정이 먼저 Play Console에 사용자로 추가(초대 수락)되어야 함**
